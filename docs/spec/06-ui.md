# 06 - UI requirements

- Click a profile to enter edit mode; all control points become visible
- Points are draggable **and** every parameter is enterable numerically (a
  number field next to each point, or in the parameter panel)
- The curvature comb updates live while dragging
- Anchors can be inserted and deleted
- Undo and redo
- Element list with visibility, duplicate and ordering
- Configurations can be saved and compared side by side (overlay mode)
- Presets, among them one matching the classic r / p1..p5 ladder (leading
  edge anchor, one mid anchor per side, trailing edge anchor)

## Notes

`ADDED 2026-09-30`:

- Degrees are used in the UI for all angles; radians everywhere behind it.
  The converting functions are named `toDegrees` and `toRadians` and live at
  the boundary.
- The `leAxisAngle` control is collapsed by default (see
  [`01-geometry.md`](01-geometry.md), leAxis).
- Every numeric field accepts a value outside the slider range; the slider
  range is a comfort default, not a constraint.
